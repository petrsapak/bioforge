## Done
- `snapshot.js` (new, pure): any web of objects as plain JSON data and back. Shared objects stay shared, loops stay
  loops, Maps and Sets come back, NaN, ±Infinity, -0 and undefined survive, and the game's data objects (cell types,
  levels, templates) are written as paths such as `CELLS.mouth`, so a restored cell points at the game's own cell
  type. A function or class instance throws, naming where it was found. Type checks don't use `instanceof`, so Sets
  made in another realm (Node's tests) count.
- `savegame.js` (new, pure): `SAVE_VERSION` (1), `SAVE_UPGRADES` and `upgradeStoredSave`; the resume state Continue
  reads (`createResumeState`, `readResumeState`), a run's snapshot (`savedRun`, `restoredRun`; kept as one JSON text,
  since it nests 130+ levels deep and the desktop save file is written indented); creature files
  (`creatureFileText`, `creatureFileName`, `readCreatureFile`, which checks every cell type and neuron).
- `progress.js` (new, browser only): brings back the design, level and saved run at the start; saves the builder's
  design within 1 s of a change, a level run every 5 real s, and everything when the menu opens and when the page
  closes (`pagehide`, `beforeunload`); resumes or drops the saved run; saves a creature to a file (a download, or the
  desktop build's save dialog) and loads one through a hidden file input.
- `menus.js` (new, browser only): the main menu (Continue, Levels, Free build, Settings, Quit), the Esc menu (its
  buttons depend on the mode it opened over), the Settings view (music, sounds, fullscreen, keys) and Esc inside a
  menu. A menu takes the keys, except M and N.
- `ui.js`: `upgradeStoredSave` before the app is built; `app.menu` and `app.progress`; the Esc steps in the builder
  (`closeOpenSheet`, `letGoOfWhatIsInHand`); the menu taking the keys; `keepProgress` in the frame loop.
- `levelview.js`, `sandbox.js`: `enterLevelMode` and `enterSandboxMode` split out of the start functions, so that
  `resumeLevelRun` and `resumeSandbox` share them; Esc opens the menu; the HUD key help says "Esc menu".
- `index.html`, `style.css`: the menu sheet and the file input; the keys sheet says what Esc does now.
- `desktop/`: `preload.js` gives the page `window.desktopWindow` (quit, toggleFullscreen, isFullscreen); `main.js`
  answers those messages. Fullscreen is answered from the remembered wish, since the window may take a moment.
- Version 0.6.0 (`data/version.js`, `desktop/package.json`, CHANGELOG). PLAN.md: a "Menus and saves" decision,
  milestone 6 done, the files in Architecture, the Desktop and Versions bullets brought up to date. CLAUDE.md: the new

## Cost
- Saving a run: First stroke's Jet 17 KB; Siege (66 cells) 154 KB in 5.9 ms; a busy Sandbox (225 cells, 478 bonds)
  524 KB in 26.5 ms, restored in 13.3 ms (Node). Because of that 26 ms, the Sandbox isn't saved every 5 s, only when
  the menu opens and when the page closes. A level's save every 5 s costs about one frame's spare time.
- The builder's design check once a second is a JSON text of the design, well under 1 ms.
