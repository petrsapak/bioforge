# Session 2026-11-11: Bioforge Lab (select all and delete)

## Discussed / decided
- The 0.8.2 work was committed and tagged `lab-v0.8.2` (the user: "commit").
- The user: "I would like to add Ctrl+A that would select all cells, and Delete that would delete selected cells".
- Chosen without asking:
  - Delete removes what is selected, by Ctrl+A or by a Shift+right-drag. A cell that is only clicked (white
    outline) is not deleted. Symmetry plays no part: exactly the selected cells go.
  - The Nucleus always stays. A selection that would leave only the Nucleus opens the Delete all question, since
    the user asked for that one to "require confirmation" (2026-10-30). A smaller selection goes at once.
  - Backspace does the same as Delete, and Cmd+A the same as Ctrl+A, for keyboards without those keys.
  - The save menu got a Delete button: in a browser the menu's name field has the keyboard, so the Delete key
    there edits the name. The menu is 280 px wide (it was 220 px) to hold three buttons in a row.
  - Both keys work in the Body and the Nerve view, and not during a locked tutorial step.
  - Version 0.8.3, since 0.8.2 is tagged.
