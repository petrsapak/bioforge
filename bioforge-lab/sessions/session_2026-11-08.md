## Splash on New game (user: "Why when I click new game there's game loading screen? No it should be only when the game starts (only before main menu)")
- Cause: New game, Load game and picking another game load the page again into that game (`restartIntoGame` in
  `menus.js`), and the splash played on every page load.
- Fix: a page loaded again into a game (`start-with` set) takes the splash out at once (`skipSplash` in
  `titleview.js`) and fades in from black as before. The splash still plays at the first start, before the main
  menu. Folded into 0.7.42, which isn't committed yet.

## Black screen after Continue (user: "I just clicked resume and the screen went black and nothing happened")
- Cause: the run Continue picked up was saved before round 2 changed Metastasis's data. A run keeps its state per
  creature, pickup and wave in the level's order, so the round 1 run had no `waves` and fewer creatures, and
  `sendWaves` threw on every frame. The frame loop stopped before the screen faded in from black. Saves are only
  dropped when the game version changes, and both builds were 0.7.42.
- Fix: `savedRun` keeps a fingerprint of the level's data (`levelFingerprint` in `savegame.js`, FNV-1a over its
  JSON), and `readResumeState` drops a level run whose level no longer matches, keeping the design and the level.
  Continue then opens the Lab on Metastasis.
- Tests: `tests/savegame.js` checks that a run with a changed or missing fingerprint is dropped. `npm test`: all
  passed. Headless Edge: a save with no fingerprint opens the Lab on Metastasis's briefing, a fresh save picks the
  run up where it was left, and there were no page errors.
