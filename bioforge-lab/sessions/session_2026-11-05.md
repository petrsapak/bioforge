## The tutorial talked about the wrong screen (user: "I was in the level and clicked lab instead of next and then the tutorial contineued explaining something in the level but I was already in the lab")
- Cause: a step had no idea where it belonged. The result step waited for Next, which the Lab button skipped, so it
  stayed up in the Lab; the same happened when leaving a run halfway, and a Lab step stayed up during a run started
  early.
- Fix: run steps carry `mode: 'level'` and each lesson with a level names its `runStep` (`data/tutorial.js`). A step
  shows only where it belongs (`isStepInPlace`) and waits hidden elsewhere. Back in the Lab while at a run step
  (`stepAfterLeavingRun`): after a won run the run's steps are passed, so the lesson ends and the next one starts;
  after a lost or unfinished run the lesson goes back to "Run the level". The last run's outcome is kept in the
  tutorial's state, since the run is gone once the player is in the Lab.
- Test: `tests/tutorial.js` (the rule, the data, and in the app: Lab instead of Next, leaving a run halfway, running
  the level early). Headless Edge: won level 1, clicked Lab, the bubble went to "Level two: reach the light".
